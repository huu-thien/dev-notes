# 05 — Exam Drills

> Bộ note tổng hợp pattern câu hỏi, exam traps, decision trees, và revision cuối trước ngày thi SAA-C03. Không phải lesson mới — chỉ hệ thống hóa kiến thức đã học ở `02-core-services`, `03-architecture-patterns`, `04-comparison-guides` thành tư duy làm bài thi.

## Thư mục này dùng để làm gì

4 file giúp chuyển từ "biết service" sang "làm đúng bài thi": nhận diện pattern câu hỏi, tránh trap quen thuộc, dùng decision tree để chọn nhanh, và ôn tập rút gọn trước ngày thi.

## Nên đọc theo thứ tự nào

Nên đọc **sau khi đã hoàn tất** `02-core-services/*`, `03-architecture-patterns/*`, và `04-comparison-guides/*`. Thư mục này giả định người đọc đã nắm kiến thức nền, chỉ tổng hợp lại để thi.
