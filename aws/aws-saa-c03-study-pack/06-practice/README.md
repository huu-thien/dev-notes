# 06 — Practice

> Câu hỏi luyện tập bám sát pattern và trap đã tổng hợp ở `05-exam-drills`. Đây là phần luyện tập, không phải lesson mới — mọi câu hỏi đều dẫn về file lý thuyết gốc để đào sâu nếu trả lời sai.

## Thư mục này dùng để làm gì

Cung cấp câu hỏi luyện tập theo nhiều dạng: scenario-based (tình huống dài, đòi hỏi phân tích requirement), topic-based (câu hỏi ngắn, kiểm tra từng cụm kiến thức/trap cụ thể), và 2 mini mock exam mô phỏng đề thi thật kèm answer explanations tổng hợp riêng.

## Nên làm sau `05-exam-drills`

Nên hoàn tất `05-exam-drills/01-common-question-patterns.md` và `02-exam-traps.md` trước khi làm practice — câu hỏi ở đây được thiết kế dựa trên đúng các pattern và trap đã học ở đó.

## Cách dùng

1. Đọc câu hỏi, tự chọn đáp án A/B/C/D trước — không xem đáp án ngay.
2. Đối chiếu với **Đáp án đúng**.
3. Đọc **Vì sao đúng** / **Vì sao các đáp án còn lại sai** (hoặc **Giải thích ngắn** + **Trap liên quan** với câu topic-based).
4. Nếu sai hoặc còn mơ hồ, mở link **Đọc lại nếu còn yếu** để quay về đúng file lý thuyết gốc.
